# Roxxy support

For setup help, start with [README.md](README.md) and [Troubleshooting](docs/TROUBLESHOOTING.md).
For ordinary bugs and feature requests, use
[GitHub issues](https://github.com/Delphos-Labs/roxxy/issues).
Search existing issues before opening a new one.

Include the Roxxy version or commit, operating system, relevant configuration,
expected behavior, and a minimal reproduction.
Remove tokens, passwords, private addresses, certificate keys, and confidential data from logs and configuration.

Do not report vulnerabilities through support issues. Follow [SECURITY.md](SECURITY.md).
If private reporting is unavailable, do not disclose vulnerability details in public.

Support is best effort. No response deadline or service-level agreement is promised.
The proposed maintainer roles and pending access setup are described in [MAINTAINERS.md](MAINTAINERS.md).
Use [CONTRIBUTING.md](CONTRIBUTING.md) if you want to submit a fix.
